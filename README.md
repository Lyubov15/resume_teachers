# Resume Teachers

Персональный сайт-резюме **Савельевой Любови Андреевны**, подготовленный для представления опыта, образования и профессиональных навыков в сфере преподавания IT-дисциплин.

## Просмотр проекта

**[Открыть сайт-резюме](https://lyubov15.github.io/resume_teachers/)**

Исходный код проекта: [GitHub — resume_teachers](https://github.com/Lyubov15/resume_teachers).

## О проекте

Сайт представляет собой адаптивную одностраничную страницу-резюме. Информация структурирована по тематическим разделам, между которыми можно переходить с помощью навигационного меню. Для мобильных устройств предусмотрено отдельное раскрывающееся меню.

На странице представлены:

- информация обо мне и профессиональных целях;
- опыт работы в образовательной сфере;
- сведения о высшем образовании;
- курсы и сертификаты;
- профессиональные и технические навыки;
- портфолио с описанием проектов, используемыми технологиями и ссылками на репозитории или демоверсии;
- дополнительная информация.

Продолжительность опыта работы и общий стаж рассчитываются средствами JavaScript на основе указанных дат.

## Используемые технологии

- **HTML5** — структура и семантическая разметка страницы;
- **CSS3** — оформление, адаптивная вёрстка и стилизация элементов;
- **JavaScript (Vanilla JS)** — интерактивное меню и расчёт периодов работы;
- **GitHub Pages** — публикация сайта.

## Запуск локально

Для локального запуска потребуется Node.js и npm.

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Lyubov15/resume_teachers.git
   cd resume_teachers
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите локальный сервер:

   ```bash
   npm start
   ```

4. Откройте в браузере адрес:

   ```text
   http://localhost:8080
   ```
