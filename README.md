## Практический опыт

В портфолио представлены проекты, демонстрирующие применение технологий на практике:
- веб-приложение для онлайн-бронирования;
- инструменты анализа веб-страниц и проверки ссылок;
- каталог автомобилей с фильтрацией и формой заявки;
- приложение для работы с комментариями;
- сервис доставки с интеграцией Яндекс.Карт;
- мессенджер с интеграцией GREEN-API;
- Telegram Mini App и бот для управления каталогом;
- геоинформационная система пространственного анализа.

## Запуск проекта

Для локального запуска необходимы Node.js и npm.

```bash
git clone https://github.com/Lyubov15/resume_teachers.git
cd resume_teachers
npm install
npm start
```

После запуска откройте в браузере `http://localhost:8080`.
