# Савельева Любовь Андреевна — преподаватель IT-дисциплин

**[Открыть сайт-резюме](https://lyubov15.github.io/resume_teachers/)**

Преподаватель IT-дисциплин с профильным образованием в области информатики и вычислительной техники и практическим опытом разработки веб-приложений. Умею разбираться в технических задачах, объяснять сложные темы понятным языком и связывать теорию с практикой.

В работе делаю акцент на доступном объяснении материала, последовательном освоении инструментов и решении прикладных задач. Считаю важным не просто познакомить обучающихся с технологиями, а помочь им понять принципы их работы и научиться применять знания самостоятельно.

## Профессиональные компетенции

- **Программирование:** JavaScript, TypeScript, Python, HTML5, CSS3.
- **Веб-разработка:** React, Next.js, Angular, Vue.js, Node.js.
- **Работа с данными и API:** REST API, PostgreSQL, SQLite, интеграции с внешними сервисами.
- **Инструменты разработки:** Git, Docker, Vite.
- **Практическая разработка:** создание веб-приложений, форм с валидацией, интерфейсов, интерактивных карт и сервисов.

## Образование и развитие

- Магистратура — «Информатика и вычислительная техника», Волгоградский государственный технический университет.
- Бакалавриат — «Экономика», Волгоградский государственный технический университет.
- Профессиональная переподготовка — «Системы искусственного интеллекта».
- Сертификат GREEN-API Developer.

Сочетание технического и экономического образования помогает рассматривать IT не только со стороны программной реализации, но и с точки зрения практических задач и процессов, для которых создаются цифровые решения.

## Практический опыт

В портфолио представлены проекты, демонстрирующие применение технологий на практике:

- веб-приложение для онлайн-бронирования;
- инструменты анализа веб-страниц и проверки ссылок;
- каталог автомобилей с фильтрацией и формой заявки;
- приложение для работы с комментариями;
- сервис доставки с интеграцией Яндекс.Карт;
- мессенджер с интеграцией GREEN-API;
- Telegram Mini App и бот для управления каталогом;
- геоинформационная система пространственного анализа.

Проекты позволяют показать не только знание синтаксиса языков программирования, но и понимание логики приложений, взаимодействия компонентов, работы с API и базами данных.

## Подход к обучению

- Объяснение технических понятий на понятных примерах.
- Переход от теории к практическим заданиям.
- Разбор ошибок и помощь в поиске самостоятельных решений.
- Адаптация объяснений к уровню подготовки обучающихся.
- Использование актуальных инструментов и примеров из разработки.

## Технологии сайта

Сайт реализован с использованием HTML5, CSS3 и JavaScript. Адаптивная вёрстка обеспечивает корректное отображение на компьютерах и мобильных устройствах. JavaScript отвечает за мобильную навигацию и автоматический расчёт периодов работы.

## Запуск проекта

Для локального запуска необходимы Node.js и npm.

```bash
git clone https://github.com/Lyubov15/resume_teachers.git
cd resume_teachers
npm install
npm start
```

После запуска откройте в браузере `http://localhost:8080`.
